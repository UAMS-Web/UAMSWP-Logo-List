Written against the unreleased `main` branch, after v2.0.2.

UAMSWP Logo List is developed in [UAMS-Web/UAMSWP-Logo-List](https://github.com/UAMS-Web/UAMSWP-Logo-List) by UAMS Web Services. The [README](https://github.com/UAMS-Web/UAMSWP-Logo-List#readme) keeps the development notes: the tests, the checks to run before a push, and the remote CI.

## Reporting a problem

Open an issue in the [issue tracker](https://github.com/UAMS-Web/UAMSWP-Logo-List/issues/new/choose). Say which page and block the problem is on, what you expected and what happened, and the plugin version from the dashboard's **Plugins** screen. Use placeholder values rather than real credentials or private details.

## Releases

Each release is listed on the [Releases](https://github.com/UAMS-Web/UAMSWP-Logo-List/releases) page with its notes. The plugin's version is the `Version` line of its header in `uamswp-logo-list.php`.

## Editing this wiki

These pages live in [`docs/wiki/`](https://github.com/UAMS-Web/UAMSWP-Logo-List/tree/main/docs/wiki) and change through a pull request like any other file. The **Publish wiki** workflow copies the folder to the wiki when a release is published, and can be run by hand. Each publish replaces the whole wiki, so an edit made in the wiki itself is lost at the next publish.
