Written against the unreleased `main` branch, after v2.0.2.

Each organization a logo list can show is one **Logo List Item**. This guide creates one with every field filled in.

## Steps

1. In the dashboard, open **Logo List Items**, then **Add New**.
2. Enter a post title. The block never shows it, but it is public: it is the title of the item's own page, the post-type archive and site search results. It is also used by the **Alphabetical by Post Title** sort order.
3. Enter **Name of Organization** (required). Use the organization's full name rather than an acronym, unless the acronym is its official name. This is the name readers see.
4. Upload **Logo of Organization**. Use a PNG with a transparent background, cropped to the edges of the logo, at least 884 by 538 pixels. A JPEG saved as a PNG keeps its solid background.
5. To link the organization, enter **URL for Organization**: its website or a UAMS page about the partnership. Two more fields appear:
   - **Link Text**: the button text in the vertical list layout. Left empty, it reads `Visit Their Website`.
   - **Link Target**: **No Override** follows the block's **Open Links in New Window?** setting; the other two choices always open this item's link in a new window or in the same window.
6. Select one or more categories in **Categories**. A block shows only items in the categories it selects, so an item with no category appears in no list.
7. Choose a **Label for Organization** if the lists that show it group or narrow organizations by something like industry, city or state. Labels are managed under **Logo List Items**, then **Labels**.
8. Enter a **Short Description** (235 characters at most) if a grid list shows short descriptions, and a **Long Description** if the organization appears in a vertical list.
9. Select **Publish**. Only published items appear in a block.

**Note:** if a logo is later deleted from the media library, the item shows its organization name in place of the logo, rather than a broken image.
